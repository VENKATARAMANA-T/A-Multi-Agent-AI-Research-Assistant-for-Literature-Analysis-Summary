# Production dependencies for a managed host.
#
# The difference from requirements.txt is what is *absent*: torch,
# transformers and sentence-transformers. Embeddings go through fastembed,
# which runs the same all-MiniLM-L6-v2 model on ONNX Runtime — a runtime the
# OCR engine already loads, so this removes a duplicate ML stack rather than
# adding one. The image drops from 3.91 GB to roughly 700 MB and resident
# memory from ~2 GB to ~500 MB, which is what makes a free tier viable.
#
# Set EMBEDDING_BACKEND=fastembed alongside this file. With torch absent and
# the setting left on "auto", get_embedder() would fall through to the hashing
# embedder and retrieval quality would quietly collapse.
